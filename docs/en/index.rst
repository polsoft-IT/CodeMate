Features
--------

* **Editor with syntax highlighting** - support for Python, Bash, PowerShell, JavaScript, SQL
* **Task scheduler** - automatic script execution on a schedule
* **Trash** - safe deletion and restoration of scripts
* **Templates** - quick creation of new scripts from templates
* **Statistics** - detailed script usage statistics
* **Search** - fast search across the entire database
* **Export/Import** - easy database transfer between computers
* **VirtualEnv** - Python virtual environment management
* **VDrive** - virtual drive for file storage
* **Terminal** - built-in terminal
* **Runner** - run scripts with full monitoring
* **Git integration** - automatic versioning of changes
* **Plugin system** - extensibility through plugins
* **Plugin marketplace** - install from an HTTPS catalog with SHA-256 verification
* **`.exe` export** - building standalone Python applications via PyInstaller
* **REST API** - run trusted scripts, job statuses and cancellation
* **Git sync** - push the database and safe fast-forward pull
